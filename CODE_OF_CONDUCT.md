# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc].

In short: be respectful, assume good faith, focus on what is best for the
community, and refrain from harassment or personal attacks. The full text is
available at the link below.

## Reporting

If you witness or experience unacceptable behavior, please report it to the
maintainer at **sycatle@pm.me**. Reports are handled confidentially. The
maintainer is responsible for clarifying standards and may take any action
deemed appropriate, including warning the offender or temporary or permanent
bans from project spaces.

## Scope

This Code of Conduct applies within all project spaces (issues, pull
requests, discussions, and any other official communication channels), and
when an individual is representing the project in public spaces.
